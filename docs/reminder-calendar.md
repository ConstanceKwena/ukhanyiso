# Reminder calendar

The reminders page lets a learner add generic next-step reminders or copy a listed funding closing date. Reminder entries are stored in browser `localStorage` on the current device; they are not sent to the backend, attached to the shared demo profile, or synchronized across devices.

The calendar can export an `.ics` file for import into Google Calendar, Apple Calendar, Outlook, or another compatible app. The external calendar app controls notifications. Ukhanyiso does not send push, email, SMS, or background notifications.

The demo uses predefined reminder types instead of asking for learner names, exam numbers, contact details, or custom free text. Treat bursary dates as prompts to confirm on the official funder website. Local browser storage is not a secure account or backup; clearing browser data removes reminders.
