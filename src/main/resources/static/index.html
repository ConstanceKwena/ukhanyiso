Privacy notice (POPIA)

Ukhanyiso uses the matric marks you enter to calculate possible course matches. In this prototype, marks are sent to the application server for calculation and are not saved to a learner profile.

Please use fictional data for this hackathon demonstration. Do not enter real identity numbers, contact details, household-income information, or upload personal documents.

Ukhanyiso is a prototype, not an official university, TVET college, NSFAS, or bursary application service. Confirm all requirements with the relevant institution.

Before public release, the project team must publish the responsible party's contact details, processing purposes, retention periods, data-subject rights, and privacy-request process.
